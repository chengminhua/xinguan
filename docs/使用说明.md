# 芯观使用说明

芯观是一个中文、只读的硬件监控面板，界面参考 Mission Center。默认打开“总览”，侧栏可以进入各项详情。

## 安装方式

### 发布包（推荐）

1. 从 GitHub Releases 下载 `芯观-<版本>-Ubuntu24.04-ARM64.zip`，解压到任意目录。
2. 在解压目录执行：

   ```bash
   bash 安装芯观.sh
   ```

3. 从应用列表搜索“芯观”启动，或在终端执行 `xinguan`。

安装脚本会校验 SHA256、确认系统为 Ubuntu 24.04 ARM64，再通过 `apt` 安装 deb 和缺失依赖。安装系统软件需要管理员权限，可能要求联网。

也可以手动安装：

```bash
sha256sum -c SHA256SUMS.txt
sudo apt install ./xinguan_*_arm64.deb
```

### 从源码运行

```bash
sudo apt install python3-gi python3-gi-cairo python3-cairo python3-psutil \
                 gir1.2-gtk-4.0 gir1.2-adw-1
./scripts/run.sh
```

把入口安装到当前用户：

```bash
./scripts/install-user.sh
```

它会写入 `~/.local/share/applications/local.ahua.HardwarePanel.desktop`、安装图标，并把 `~/.local/bin/xinguan` 链接到源码启动脚本。`./scripts/uninstall-user.sh` 可撤销。两者都不需要管理员权限，也不设置开机自启。

## 页面

| 页面 | 内容 |
| --- | --- |
| 总览 | CPU、内存、网络、功率、温度、风扇、电池卡片 |
| 处理器 | CPU 总占用、各逻辑核心、平均频率、GPU 占用 |
| 内存 | 物理内存、可用内存、交换空间 |
| 网络 | 活动物理网卡的下载 / 上传速率与趋势 |
| 功率 | CPU / GPU / Other 三路部件功率 |
| 温度 | CPU / GPU 温度与系统温区 |
| 风扇 | 两路风扇转速 |
| 电池 | 电量、状态、电压、电流、供电来源 |

常规指标每秒更新；GPU 占用和命名温度在后台约每 3 秒查询一次，因此可能比 CPU 数字稍旧。右上角按钮可暂停 / 恢复刷新和切换浅色 / 深色。曲线保留最近 60 次采样。

`—` 表示当前无法读取，不代表零，也不代表传感器一定损坏。

## 数据边界

### 整机功耗

**插电时不提供整机总功耗。** 本机没有可靠的整机功率接口，界面明确显示“插电时不可读”。

CPU、GPU、Other 分别读取 PM01、PM02、PM00，它们是不同部件的功率，不能相加冒充整机功耗。Other 是厂商定义的其他部件功率，不等于电脑其余全部耗电。

只有同时满足以下条件，才显示“电池侧整机估算”：

- 所有已知外部供电都确认断开；
- 只有一块系统电池；
- 电池状态为正在放电；
- 电压、电流或 `power_now` 读数有效。

电池充满时传感器可能仍有残余电流，因此不会据此推算整机耗电。鼠标、键盘等外设电池（`scope=Device`）不作为系统电池。

### 风扇

界面只显示两路风扇 RPM。本机没有 `pwm`、`pwm_enable` 或目标转速接口，`mthreads-smi` / `mthreads-gmi` 也没有设置风扇转速的命令，`cooling_device` 的状态不能当作 PWM 百分比。因此本项目不提供风扇滑块，也不直接写 `/sys` 风扇接口。

### 网络

速率使用累计字节数的相邻采样差值，并按实际经过时间计算。只统计有真实设备路径且处于活动状态的物理网卡；`lo`、VPN 隧道和 Docker 等虚拟接口会列为排除项，避免与物理网卡重复计数。

首次采样只建立字节计数基线，所以网络页面可能短暂显示“正在等待第二次采样…”。网卡刚出现或计数器重置时，该区间显示“—”，不会绘制虚假尖峰。单位按数值显示为 B/s、KiB/s 或 MiB/s。

### 温度与电池

固件的 TZ07 是功率保护字段，不作为摄氏温度显示。只有能确认名称的 CPU / GPU 温度才单独标注，其余保留传感器名称（如“温区 TZ00”）。

电池功率只描述电池端充放电；插电期间不能代表整机耗电。

## 资源占用

在 AIBOOK / M1000 上的短时测量（2026-10-12，约 182 秒）：

- 应用及厂商查询子进程的平均 CPU 占用约 1.8%（单核 = 100%）；
- 常驻内存合计约 203–219 MiB。

这是三分钟测试结果，不代表长期稳定性或所有机器的表现。

## 常见问题

**为什么插电时看不到整机功耗？**
没有可靠接口。宁可不显示，也不用三路相加或电池读数冒充。

**为什么 GPU 是“—”？**
GPU 数据依赖设备原有的 `mthreads-smi`。未安装、查询超时或数据过期时，其余指标仍会工作。

**为什么网络一直显示“正在等待第二次采样”？**
首次采样只建立基线，下一次刷新后才会出现速率。如果持续如此，说明没有可确认的活动物理网卡。

**能调风扇吗？**
不能。当前只有转速读取接口，没有可安全写入的调速接口。

**应用 ID 为什么是 `local.ahua.HardwarePanel`？**
它沿用早期本机版本的标识，以保证桌面入口、图标和单实例行为兼容；安装到其他系统不影响使用。

## 卸载

发布包安装：

```bash
sudo apt remove xinguan
```

源码安装：

```bash
./scripts/uninstall-user.sh
```

## 隐私

程序只读取本机 `/proc`、`/sys`、psutil 和可选的 `mthreads-smi` 输出；不上传数据，不启动后台服务，关闭窗口即停止采集。发布包不包含个人路径、日志、凭证或诊断数据。

## 数据来源

| 指标 | 来源 |
| --- | --- |
| CPU 占用、频率 | `/proc/stat`、`cpufreq/scaling_cur_freq` |
| 内存、交换空间 | `psutil` |
| GPU 占用、CPU / GPU 温度 | `mthreads-smi -q cpu gpu` |
| 部件功率 | `/sys/bus/acpi/devices/ACPI000D:*/power1_average` |
| 系统温区 | `/sys/class/thermal/thermal_zone*/temp` |
| 风扇 | `/sys/class/hwmon/hwmon*/fan*_input` |
| 电池、外部供电 | `/sys/class/power_supply/*` |
| 网络 | `psutil.net_io_counters(pernic=True)` 与 `/sys/class/net/*/device` |
